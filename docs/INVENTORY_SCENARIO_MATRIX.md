## Summary

**Counts:** COVERED 34 · PARTIAL 35 · NONE 3 (S01, S62, S72).

**A code gap, not only a test gap: S25.** Per-op `rejected/unsupported_version` is dropped from the queue like any other refusal (queue.ts:342-357); no client code names it, so "kept, and the app asks to be updated" looks unimplemented. Worth confirming before phase 9.

**Gaps by the cheapest layer that can close them**
- **API contract (AC):** S21 (visible after joining), S22 (non-member and deactivated over every endpoint, guest ops/ with a real item), S28 (list default_mode decides), S31 (history `source`), S50 (deleted list leaves shopping-list/count; widget for an archived project), S20 (a partly-ordered units row in `count`).
- **TS unit, packages/inventory (TQ):** S09 (mixed answer: empty queue + three notices), S27 (clock corrected between tap and delivery; hold with a wrong clock), S38 (two stale notices), S59 (250 drain in order), S25 (after the fix).
- **TS unit, shopping-app (TA):** S03/S04/S06 (reason on screen), S11 (no old number in the dialog), S15 (Arrived asks which; other stays open, plus EU status), S16 (skewed clock), S17 (who/when), S18 (Done after reload, six-hour reset), S35 (Pending lists held entries with send/discard), S36 (row shows B's change), S41 (discard first in UI, rest sent), S60 (below-minimum row under Running low), S64 ("bought since" + cancel offer), S71 (no undo after Arrived), S01 (two controllers, one finishes).
- **E2E desktop (ED):** S40 (automatic retry through a 40 s 502 window), S51 (`/shopping` redirect), S55 (two real pages), S62 (same user, two contexts), S26 level/± offline taps.
- **Gate / dev deploys:** S57 (gate on main ref), S61 (feature ref → rollback → main sequence).

**Only a real device can show**
- Phone: S26 airplane mode plus a cold start from the icon; S52 kill, reopen within 2 h and next day, background sync with the app closed (M10); S33 500 items within the render budget; S34 TalkBack names and 130 % font scale; S72 two installs from both hostnames; S23 an expired session on each hostname, including the Pocket ID proxy sign-in; S25 an installed app updating its worker with a queue present.
- Two real phones: confirmation runs for S01, S24 and S62 (phone + desktop).
- Desktop Brave: S55 real cross-tab locks; S62's desktop side.
- Confirmation only (already automated, a real radio adds fidelity): S42, S66, S16 with a moved phone clock.
